# Matriz genérica

O projeto contém `Matriz<T>`, uma matriz bidimensional de tamanho fixo com operações para armazenar e recuperar elementos, obter linhas, colunas e diagonal principal. O programa `PrincipalMatriz` lê 25 inteiros, ordena-os e os reinsere em uma matriz 5 × 5.

Na pasta deste projeto, compile com:

```text
javac -encoding UTF-8 -d out src/matriz/*.java
```

Execute com:

```text
java -cp out matriz.PrincipalMatriz
```
